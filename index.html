Keyboard Shortcuts (While Streaming)

M Key Toggle Audio Mute / Unmute
C Key Toggle Auto Subtitles On / Off
F Key Toggle Fullscreen Mode

Requirements & Stream Debugging
1. Channels Not Loading? Siguraduhing ang iyong channels.m3u file ay nasa root folder kasama ng iyong index.html file bago i-deploy sa host system.
2. Subtitle Synchronization: Ang mga subtitle ay awtomatikong lumalabas kapag ang live stream source URL link ay may nakapaloob na embedded caption text track profiles.
3. Security Layers: Naka-disable ang right-click block access at common inspection dynamic hotkeys upang maprotektahan ang distribution architecture source elements ng network logs mo.
